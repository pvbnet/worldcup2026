# Contributing

Thanks for your interest in this project.

## Getting started

1. Fork the repository and clone your fork.
2. Follow the **Setup** section in [README.md](README.md) (Python 3.12.3, Node 18+, model venv, dashboard venv, `fetch_data.py`, `ingest.py`).
3. Run the backend and frontend (`dashboard/backend/run.sh` and `dashboard/frontend/run.sh`, or `./start-dashboard.sh` from the repo root).

## Pull requests

- Open PRs against the `main` branch.
- Keep changes focused on the problem you are solving.
- Update [README.md](README.md) if behavior or setup steps change.

## Questions

Open a [GitHub Issue](https://github.com/pvbnet/worldcup2026/issues) for bugs, ideas, or questions.
