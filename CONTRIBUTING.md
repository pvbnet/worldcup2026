# Contributing

Thanks for your interest in this project.

## Getting started

1. Fork the repository and clone your fork.
2. Follow [docs/dev-setup.md](docs/dev-setup.md) for setup (requirements, venvs, model data).
3. Run the backend and frontend (`dashboard/backend/run.sh` and `dashboard/frontend/run.sh`, or `./start-dashboard-local.sh` from the repo root).

## Pull requests

- Open PRs against the `main` branch.
- Keep changes focused on the problem you are solving.
- Update [README.md](README.md) or [docs/dev-setup.md](docs/dev-setup.md) if behavior or setup steps change.

## Questions

Open a [GitHub Issue](https://github.com/pvbnet/worldcup2026/issues) for bugs, ideas, or questions.
