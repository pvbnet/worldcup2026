# Security policy

This project is a **local / development research dashboard** (FastAPI + React). It is not
intended as a hardened production service exposed to the public internet.

## Reporting a vulnerability

If you believe you have found a security issue in this repository:

1. Prefer [GitHub Security Advisories](https://github.com/pvbnet/worldcup2026/security/advisories/new) (private report), or
2. Open a minimal public issue at [github.com/pvbnet/worldcup2026/issues](https://github.com/pvbnet/worldcup2026/issues) if the issue is low severity and does not expose users to immediate harm.

Please do not open public issues for sensitive vulnerabilities before a fix is available.

## Scope

In scope: this repository’s application code, dependencies, and documented setup paths.

Out of scope: third-party data hosts (openfootball, FIFA ranking source sites), and deployments you run yourself outside this repo’s defaults.
